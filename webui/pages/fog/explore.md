# Fog — explore unit

Frontend-design fog found while building the Explore pages (frame assumes something the core/data cannot provide,
or the spec is ambiguous). Inventory items F1–F25 (`webui/pages/inventory/explore.md`) still stand; these are the
ones the build hit, restated with what the shell does today.

- **Canon channel ids vs live ids** · Live `/api/recordings` puts M2_aug fs1 at 1–16, fs2 at 17–32, `M2_concat_fs1` at 33–48 and M4 at 49–64; the canon has M3_jul (8 ch) and L_LM (5 ch) instead. The fixture pages use fs1 1–16, fs2 17–32, M3_jul 33–40, L_LM 41–45, M4 49–64, so `#/explore/signal/4` and `/52` agree in both modes but ids 33–48 mean different recordings · a deep link from a demo page into a live page can open the wrong channel · inventory F1, spec §0.
- **Live recordings are not the canon** · the recordings menu (frame 1b) lists what the bridge serves (`M2_concat_fs1.mat`, `Fig2A_dt0p1.csv`, `Mushroom_…`), and the bridge has no `fs_source`, so `10 Hz?` / `fs inferred` cannot be shown live · the frame's amber inferred-fs row never appears · frame explore-1b, §0.
- **Pager `1 / 5` counts** · live has 6 files (M4 included), so the pager reads `1 / 6`; the frame's 5 is the canon · harmless, but a critic comparing to the frame will see it · frame explore-1.
- **Morphology tags on a database with none** · the rail's tag filter is enabled on demo counts (sharkfin 412 across 11 of 16) and dims channels with no tagged span; the live coverage payload has no tag dimension, so the map itself is not re-counted by tag · ticking a tag changes the readout and row dimming, not the cell shades · inventory F2/F5, §5.1.
- **Runs / method filter on Corpus** · no bridge parameter filters coverage by run or method; the chips change their label and say "demo only — the live map counts every run" · a user can believe the map is filtered when it is not unless they read the note · §5.1.
- **Default verdict ticks** · the frame ticks only `seed` and `interesting`; applied live, the map counts only those verdicts, which differs from the previous live default (all five) · the first screen of Corpus now shows fewer spans than before · frame explore-1.
- **Seed colour** · canon now makes `seed` green (human verdict, §3) while frames explore-1/2b draw it blue; the pages follow the canon · verdict dots differ from the frames · canon commit 6681ae3.
- **`?motif=233`** · the ordinal walks the merged list (live annotations + live detections + demo detections from checked runs), so 233 lands on whatever is 233rd, not on the frame's fixture MOTIF at 277.312 h; the list also re-numbers when the picker changes · a shared URL can open a different motif after a picker change · inventory F6, frame explore-2.
- **Medoid overlay on a live trace** · the F-03 medoid is synthetic canon (~0.34 mV deep); the live CH4_A2 motif windows vary by ~0.02 mV, so drawing both on one mV scale squashes the live trace. The overlay defaults off (frame draws it on) · the frame's picture cannot be honest with live data until families exist · §3 D5, frame explore-2.
- **Density ribbon on the canon channel** · live CH4_A2 has 0 detections; the ribbon counts demo detections from visible runs instead, and the header still reads the live `0 detections` · two numbers on one page disagree (header live, ribbons/drawer demo) · frame explore-2.
- **Picker chip copy** · the chip reads checked runs · distinct methods (`3 of 6 runs · 3 methods`); no picker state produces the frame's `6 runs · 4 methods` · inventory conflict 5 / F8.
- **Drawer scope default** · the frame shows `scope visible span` with `96 of 1,284` matching; 96 matrix-profile detections inside a 2 h span would crowd the span tier, so the fixture spreads them across the channel and the default scope is `whole channel` (`visible span` still filters honestly) · frame explore-2c, B28.
- **Drawer on live channels** · element, quality, structure, status, spike-train length, method, adjudication and nearest family are disabled with "not in this database"; export and send work on the live rows · the drawer is much thinner live than in the frames · inventory F9.
- **Drawer rows vs span tier** · on the canon channel the drawer's annotation rows are demo canon at other times than the live annotations drawn in the span tier; clicking a demo row centres the live signal at that time, where no band is drawn · the row and the plot can disagree · frame explore-2b.
- **`Review this motif` / `Take span for Review` queue** · both stage into an "Explore spans" queue that has no canon id (q-12/15/18/19 are the others) · Review cannot show where they went · inventory F13.
- **`D` / `Esc` with the drawer** · the drawer replaces the span/motif/action tiers (as frames 2b–2d draw it) rather than overlaying them, so the span tier unmounts while it is open · §5.3 says "overlays the lower screen" · inventory conflict 1.
- **Cross-channel bins and thresholds** · artifact r ≥ 0.95 at |lag| < 0.5 s, propagation r ≥ 0.6, independent below, no match beyond max lag — all proposed; lag/r are a seeded table and `computed on whole channel` just perturbs them · nothing about the page is a result · inventory F16/F17, §5.4.
- **Cross-channel colours** · bins use green for independent and amber for propagation (frame), against §3's green = human/above chance · flagged, kept as drawn · inventory conflict 2.
- **Cross-channel window from Signal** · `?window=motif-<n>` only relabels the window; the fixture traces are always MOTIF_233 · entering from another motif shows the wrong waveform under the right label · §5.4.
- **Span edit time format** · fields show `148.6019 h · #534,967` (hours since start) instead of the frame's clock `148:36:07` · §0 time display wins · inventory conflict 1.
- **Span edit rev 2 status before save** · the frame labels rev 2 `current` while unsaved; the page shows `current once saved` (grey) until Save, then `current` · inventory §4.2.
- **Span edit family staleness** · §4.2 says an extent edit on the medoid invalidates F-03's distances; the frame omits it, the page adds a fourth (amber) check line · spec wins over frame, flagged for the fidelity critic.
- **Held-out member id** · no canon member lives on M4; `m-0917` is invented to reach the held-out state of span edit · §0 has no such member.
