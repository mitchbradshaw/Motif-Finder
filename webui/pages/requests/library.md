# Library — requests for shared code (kit / shell)

Each: what · where · why. All are worked around inside `webui/client/src/library/`; none block the Library.

1. **Disabled `danger` buttons look enabled** · `kit/kit.css` (`.k-btn.danger` is declared after `.k-btn:disabled` with the same specificity, so the red border and text win) · a blocked Delete must read as blocked. Fix: `.k-btn.danger:disabled { border-color: var(--border); color: var(--muted-2); background: var(--k-fill); }`. Workaround: WindowSetsPage uses the `default` variant while the button is disabled.
2. **Log-scale x for `Histogram`, with bin-edge rules and out-of-range tinting** · `kit/plots.tsx` · the grouping editor draws frequency content and timescale on a log axis with bin edges and an `outside range` band (frame library-4). Workaround: local `FeatureHistogram` in `library/GroupingPage.tsx`.
3. **Deep-link state that resets on a real navigation** · `kit/hooks.ts` · hash-only navigation keeps components mounted, so a surface opened or a sim forced from `?modal=` / `?state=` keeps its draft or forced state when the next deep link lands on the same route (critics and the smoke then see stale state). Workaround: `useExternalNavKey()` in `library/chrome.tsx` (counts hashchange events that carry `newURL`; `setQuery(…, true)` dispatches one without) used as a React `key`; forced sims read `getSim(id)` live and reset on unmount. A kit `useForcedSim(id, queryKey)` would remove the per-page copies.
4. **Button label font in narrow rails** · `kit/kit.css` · frames draw action buttons in Inter; mono labels overflow the 316 px Library rails ("Send 19 unjudged motifs to Review →"). Workaround: `.lib-rail-actions .k-btn { font-family: var(--font-ui) }`, scoped to the Library.
5. **One "send to Review as a queue" call** · `api/review.ts` (Review owns it) · Library, Discovery and Models all create named queues (P20); a typed `createReviewQueue(name, items)` returning `Sourced` would replace per-workspace toasts. Workaround: `useQueueToast()` in `library/chrome.tsx`.
