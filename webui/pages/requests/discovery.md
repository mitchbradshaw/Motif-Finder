# Discovery — shared/kit requests

- **Glyph registry: seeded search, drop detection, noise floor, human reference.** `kit/glyphs.tsx` aliases `seeded_search` → `detection.seeded_search`, `drop_detection` → `detection.drop`, `noise_floor` → `preprocessing.noise_floor`, none of which exist in `analyse/glyphs.tsx`, so they fall back to a generic signature glyph. Frames discovery-1/-1b/-3/-3b draw specific thumbnails. Worked around with `discovery/glyphs.tsx` (local). Where: `analyse/glyphs.tsx` registry. Why: §6.8 "each run with its algorithm glyph".
- **Button `disabledReason` inside `DisabledReason`.** The kit warns `disabled Button has no disabledReason` even when the Button is wrapped in `DisabledReason`; builders must pass the reason twice. Where: `kit/display.tsx` Button warning. Why: noise / duplication.
- **Table with expandable child rows.** The scoreboard needs parent rows that expand into per-channel child rows that sort with their parent (§7.3). `Table` has `groupBy` but no expand. Worked around with a local table in `RunsPage.tsx`. Where: `kit/Table.tsx`.
- **Histogram with a draggable threshold and a background (null) series.** Seed search's "where to cut" (§7.6) needs the null distribution behind the kept bars and a draggable line; `Histogram` draws the overlay on top and the threshold is static. Worked around locally. Where: `kit/plots.tsx`.
- **A multi-track time plot (signal + event tracks on one x axis, one crosshair).** Seed search's distance profile (signal · distance · matches) and Compare's *where A and B fire* (signal · A · B · agreement) both need a stack of tracks sharing one hour axis, one hover crosshair and one tooltip. `Trace` draws one series with its own padding, so both pages hand-roll an SVG to keep the tracks aligned with the trace. Where: `kit/plots.tsx` (a `TrackedTrace` / `tracks` prop on `Trace`). Why: §7.6, §7.7 — and two builders re-implementing the same crosshair is how the two drift apart.
- **Stacked proportional bar with in-bar counts and clickable segments.** *Set overlap* needs one bar per channel whose width is the row total, segments labelled with their counts inside, each segment clickable (it sets the stepper filter). `Bars` puts value labels outside and has `onBarClick` per bar, not per segment. Worked around with a flex bar in `ComparePage.tsx`. Where: `kit/plots.tsx` `Bars`. Why: frame discovery-3.
- **`StatTile info` takes a node, not a string.** The README lists `info?` beside `InfoTip`'s text prop, so passing a string renders the explanation inline next to the label (it reads as part of the label). Either accept a string and wrap it, or say "node" in the README. Where: `kit/display.tsx` `StatTile`, `kit/README.md`. Why: it silently produces "A precisionOf A's detections…" on the page.
- **`Pager` has no keyboard stepping.** Stepping through 106 disagreements (compare, stages) wants ←/→ once the pager has focus; today each page would have to add its own key handler. Where: `kit/nav.tsx` `Pager`. Why: §7.7 / §7.8 stepping.
