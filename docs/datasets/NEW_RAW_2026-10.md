# New raw recordings, October 2026

The researcher added six raw files to `DATA/raw` (2026-10-18) and asked for MJu26a to be put on an even
10 Hz grid as the parent of L_LM_Jul_26_J. This note records what each became, from the real runs of
2026-10-19 (manager session, main at `b8aefa3`/`b8752ce`; database backed up first to
`DATA/db/backups/annotations.sqlite.pre-datasets-derive-20261019-211013`, integrity `ok`).

## In plain words

A recording is a long list of voltages taken at regular ticks. To use one we must know how often the
ticks came (the sampling rate) and what the numbers are measured in (volts or millivolts). These files
store their clock as a MATLAB `duration` object Python cannot open, so every rate below was worked out
from the length or stated by the researcher — none was read from the file. A file holding exactly 20 days
of samples at 10 per second, plus the closing sample, is taken to be 10 Hz and labelled *inferred, not
read*. The unit comes from the size of the numbers: values around ±1 are volts, values in the hundreds
are millivolts.

Two things did not go as first planned:
- **L_LM is not linked to MJu26a.** The check that L_LM is a ×1000 copy of MJu26a failed (table below):
  each L_LM channel does pair with the MJu26a channel the researcher suspected, at the same start, but the
  match is far from a copy in many stretches. The researcher decided (Q47, 2026-10-19): do not link.
- **CO and LM were not derived here.** Another agent derived them at 2 Hz the same day (`CO_fs2`,
  `LM_fs2`, registered 2026-10-19 04:12 UTC); a 10 Hz copy beside them would be a second recording of the
  same data (the researcher, 2026-10-19).

## The L_LM ↔ MJu26a check (why there is no parent link)

`derive_mju26a_fs10.py` high-passes both signals (each minus a 60 s moving mean), takes three windows of
10,000 samples at 25 %, 50 % and 75 % through L_LM, and searches every MJu26a_fs10 channel and offsets of
±36,000 samples, refining the best three parents to a fractional offset. A link needs refined r ≥ 0.95 on
all three windows, a lead of ≥ 0.1 over the next parent, and one offset on all three.

## How to reproduce

From the main checkout (each `--dry-run` writes nothing):

    python scripts/derive_mju26a_fs10.py --dry-run
    python scripts/derive_mju26a_fs10.py --skip-link
    python scripts/derive_raw_mat.py SH SO F2B --dry-run
    python scripts/derive_raw_mat.py SH SO F2B
    python scripts/derive_raw_mat.py L_R_Aug_26_PD_raw --fs 10 --fs-stated-by "the researcher (2026-10-19)"
    # to READ the rates instead (MATLAB R2025b): matlab -batch "addpath scripts; export_mat_time()"

Each derived directory's `manifest.json` carries the full reasoning (`fs_note`, `units`, `resampling`),
and each registration is in the audit log (Settings › Audit).
