\chapter{Numbers ledger}
\label{app:ledger}

Every number reported in the results chapters is traced here to the file that produced it and the script or route that wrote that file. The full ledger, with about 90 rows, is kept in the repository as \texttt{docs/thesis/numbers\_ledger.md}. This appendix carries the headline rows and the resolution of every disagreement between earlier documents. Status \emph{verified} means recomputed from the database (read-only) or read from a machine-written results file.
